Atlas Search 2.4

Release date: 2026-05-18.

Highlights

  • Introduced hybrid lexical + vector retrieval with reciprocal-rank fusion.
  • Added source-level access-control filters before reranking.
  • Changed the default result limit from 8 to 12 candidates before reranking.

Known issue

CSV columns containing embedded newlines may display truncated snippets in the preview panel; retrieval is unaffected.
